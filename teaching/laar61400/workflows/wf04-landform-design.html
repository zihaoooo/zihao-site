Session 1 — Build It by Hand in Rhino
00–01 File Setup + Base Slope Rhino
File setup — DocumentProperties → Units → Feet, Absolute tolerance → 0.1. Save as wf04-landform.3dm.
Tolerance = how far apart two edges can be and still join. Patch only approximates its edge, so 0.01 ft is too tight; 0.1 ft (about 1") joins and is invisible at 1"=20'.
Build the base slope — Rectangle → 0,0 to 300,180. PlanarSrf from the rectangle. Press F10 to show control points. Ctrl+Shift+click one short edge to sub-object select it. Gumball Z → type 10 → Enter. F11 to hide points.
Sub-object selection (Ctrl+Shift+click) selects faces, edges, or vertices without exploding the object. Use it whenever you need to move part of a surface.
Ways to Build a Surface Rhino
Every surface is built from curves. The curves you have decide the command.
CommandGive itLandform use
Lofttwo or more section curvesramp, terrace edge, wall face
Sweep1 / Sweep2a profile + one or two rails (paths)berm or swale along a path, channel
Patcha boundary curve + points or curves inside itmound or bowl inside a footprint
This exercise uses Patch: a mound is defined by its edge and its peak, not by sections or a path.
02 Draw a Footprint + Control Point Rhino
In the Top viewport, draw a closed curve, flat: InterpCrv, Ellipse, or freehand. Place a Point inside it.
  • Select the point → Gumball Z → drag above the slope for a mound, below it for a bowl or swale
  • Check its height in the Front or Right viewport
The curve is the breakline: where the landform stops and existing grade continues. The point is the peak or low point.
03 Project + Split Rhino
Cut a hole in the slope where the landform goes:
  • In the Top viewport: Project → select the footprint → Enter → select the slope → Enter. The curve now sits on existing grade.
  • Split → select the slope → Enter → select the projected curve → Enter
  • Delete the cut-out piece inside the curve. Keep the slope with the hole.
04 Patch + Join Rhino
Fill the hole with the new landform:
  • Patch → select the projected curve and the control point → Enter
  • In the dialog: Surface U/V spans → 10; lower Stiffness for a looser, more organic form → OK
  • Join → the slope with the hole + the Patch. The command line should read "joined into one polysurface".
  • Check: ShowEdges → Naked edges. Only the site boundary should highlight.
If Join leaves two pieces, check the 0.1 ft tolerance from Step 00.
05 Contour + Read Rhino
Contour → select the joined surface → Enter → base point 0,0,0 → direction point 0,0,1 → distance 1 → Enter.
  • Contours that V upstream → valley or drainage path. V downstream → ridge.
  • Contours kink at the breakline: the landform stops there, like at a curb
  • Where does water go? Where does it collect?
Want a taller mound? Delete the Patch and the contours, move the point, and redo Steps 04–05. Session 2 removes that loop.
06 Capture the Isometric View Rhino
Set up a standard isometric view and save it directly from Rhino:
  • In any viewport title, right-click → Set View → Isometric → choose SW, SE, NE, or NW, whichever shows the landform most clearly
  • Type PrintDisplay → On, to show lineweights in the viewport
  • Type PrintScreen → File → save as PNG or JPEG
PrintScreen to File captures exactly what you see in the viewport at screen resolution. No layout or PDF needed for this view.
Session 2 — Rebuild It in Grasshopper
07 Grasshopper Basics Grasshopper
Session 2 builds the same landform again. Every Rhino command from Session 1 becomes a component (see the reference table below). Type Grasshopper to open the canvas.
  • Add a component: double-click the empty canvas → type its name → Enter
  • Inputs on the left, outputs on the right. Drag a wire from an output to an input.
  • Params (Surface, Curve, Point) hold Rhino geometry: right-click → Set One … → click it in Rhino
  • Hover any input to see what it expects. Orange = warning, red = error.
  • Grasshopper geometry is a preview only. It becomes real Rhino geometry when you Bake it.
Start from scratch: a new Rhino file, saved as wf04-landform-gh.3dm. Redo Steps 00–02 (setup, slope, footprint, point). Rhino only holds these inputs; everything after happens in Grasshopper. Save the definition as wf04-landform.gh.
08 Reference → Project → Split Grasshopper
  • Surface param → Set One Surface → the slope
  • Curve param → Set One Curve → the footprint
  • Project → footprint → Curve input, slope → Brep input, Unit Z → Direction input
  • Surface Split → slope → Surface input, projected curve → Curves input
  • List Item → Fragments → List input; set Index to whichever previews as the slope with the hole
List Item replaces "delete the cut-out piece": Surface Split returns both pieces, and you pick the one to keep.
09 Patch → Join → Contour Grasshopper
  • Point param → Set One Point → the control point
  • Patch → projected curve → Curves input, Point → Points input
  • Join Breps → List Item output + Patch output → Breps input (hold Shift while dragging the second wire)
  • Contour → joined terrain → Shape input; Number Slider (0.5–5 ft) → Distance input (contour interval)
Compare with Session 1: same model, same contours. The difference is in the next step.
10 Make It Live Rhino Grasshopper
Edit the inputs in Rhino and watch everything downstream update. No redoing steps.
  • Move the control point up or down → taller mound, deeper bowl
  • Move it off-center → one steep side, one gentle side
  • Edit the footprint (F10 control points) → change where the landform stops
  • Patch Spans and Flexibility inputs: more detail, looser form
  • Drag the contour slider → finer or coarser interval
Iterate until the contours read as a deliberate landform, then capture a new isometric of the final version (Step 06).
11 Bake + Produce the Contour Plan Rhino
Bake the finished geometry and produce a print-ready layout:
  • Right-click the Contour Contours output → Bake → layer CONTOURS-DESIGN
  • Make2D → Top viewport → flat linework
  • Layout → 1" = 20' (1:240) on 11 × 17
  • Add: north arrow, scale bar, contour interval note, title block
  • Plot to PDF
