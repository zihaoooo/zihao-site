Session 1 — A Catalog of Landforms, by Hand
00–01 File Setup + Base Slope Rhino
File setup — DocumentProperties → Units → Feet, Absolute tolerance → 0.1. Save as wf04-landform.3dm.
Tolerance = how far apart two edges can be and still join. Patch only approximates its edge, so 0.01 ft is too tight; 0.1 ft (about 1") joins and is invisible at 1"=20'.
Build the base slope — Rectangle → 0,0 to 300,180. PlanarSrf from the rectangle. Press F10 to show control points. Ctrl+Shift+click one short edge to sub-object select it. Gumball Z → type 10 → Enter. F11 to hide points.
Sub-object selection (Ctrl+Shift+click) selects faces, edges, or vertices without exploding the object. Use it whenever you need to move part of a surface.
Ways to Build a Surface Rhino
Every surface is built from curves. The curves you have decide the command.
CommandGive itLandform use
Lofttwo or more section curvesramp, terrace edge, wall face
Sweep1 / Sweep2a profile + one or two rails (paths)berm or swale along a path, channel
Patcha boundary curve + points or curves inside itmound or bowl inside a footprint
This exercise uses Patch: a mound is defined by its edge and its peak, not by sections or a path.
02 Draw a Footprint + Control Point Rhino
In the Top viewport, draw a closed curve, flat: InterpCrv, Ellipse, or freehand. Place a Point inside it.
  • Select the point → Gumball Z → drag above the slope for a mound
  • Check its height in the Front or Right viewport
  • Copy the slope, curve, and point 400 ft to the right (Copy, Ortho on). You will build the same mound two ways, side by side.
The curve is the breakline: where the landform stops and existing grade continues. The point is the peak.
03 Method A: Patch Everything Rhino
On the left copy, rebuild the whole slope as one Patch:
  • DupBorder → select the slope → its edge as a curve
  • In the Top viewport: Project → the footprint → onto the slope. The curve now sits on existing grade.
  • Patch → the border, the projected curve, and the point → Enter → Surface U/V spans 10 → OK
  • Hide the original slope
One surface, nothing to join. But the mound is part of the whole field, so it can shift grade outside its footprint.
04 Method B: Split → Patch → Join Rhino
On the right copy, change the ground only inside the footprint:
  • Project → the footprint → onto the slope
  • Split → the slope → with the projected curve. Delete the cut-out piece.
  • Patch → the projected curve and the point → Enter → spans 10 → OK
  • Join → the slope with the hole + the Patch → "joined into one polysurface"
  • Check: ShowEdges → Naked edges. Only the site boundary should highlight.
More steps, but existing grade stays untouched outside the curve, the way a real landform stops at a curb. If Join fails, check the 0.1 ft tolerance from Step 00.
05 Contour Both: A First Look at Grasshopper Grasshopper
Rhino's Contour command draws contours once. In Grasshopper they stay live. Type Grasshopper:
  • Double-click the canvas → type Brep → Enter. Right-click it → Set Multiple Breps → select both results
  • Double-click → Contour. Wire Brep → Shape input
  • Double-click → Number Slider (0.5–5) → Distance input. Drag it and watch.
Compare A and B. In A, contours bend outside the footprint. In B, they kink at the breakline and stay straight beyond it. Session 2 builds the whole model this way.
06 Build the Catalog Rhino
Repeat Steps 02–04 for three landform types, each on its own copy of the slope, side by side. Pick Method A or B for each.
  • Mound → control point above the slope. Sheds water.
  • Basin → control point below the slope. Holds water.
  • Swale or ridge → an open curve inside the footprint, moved below or above the slope, instead of a point. Directs water.
Add all three to the Brep param (Set Multiple Breps) and read the contours. Where does water go on each?
07 Capture the Catalog Isometric Rhino
One isometric view with all three landforms and their contours:
  • Right-click the Contour Contours output → Bake, so the contours are real Rhino curves
  • In any viewport title, right-click → Set View → Isometric → SW, SE, NE, or NW, whichever reads best
  • Type PrintDisplay → On, to show lineweights in the viewport
  • Type ViewCaptureToFile → set width to 3000 px → uncheck Grid and Axes → Save as PNG
  • Check Transparent background if the image goes onto a colored board
ViewCaptureToFile renders the active viewport at any size, so it stays sharp in print, unlike a screenshot. This is Part 1 of the assignment. Want to change a landform now? Delete it and redo its steps by hand. Session 2 removes that loop.
Session 2 — Combine Them in Grasshopper
08 Set Up the Site Rhino
Start from scratch: a new Rhino file, saved as wf04-site.3dm. Redo Steps 00–01 (setup, slope).
  • Draw the three footprints from your catalog on the one slope. Keep them from touching.
  • Add each one's control: a point for the mound and basin, a curve for the swale or ridge
Rhino only holds these inputs. Everything after happens in Grasshopper. Save the definition as wf04-site.gh.
09 Grasshopper Basics Grasshopper
Every Rhino command from Session 1 becomes a component (see the reference table below).
  • Add a component: double-click the empty canvas → type its name → Enter
  • Inputs on the left, outputs on the right. Drag a wire from an output to an input.
  • Params (Surface, Curve, Point) hold Rhino geometry: right-click → Set One … → click it in Rhino
  • Hover any input to see what it expects. Orange = warning, red = error.
  • Grasshopper geometry is a preview only. It becomes real Rhino geometry when you Bake it.
10 Project → Split Grasshopper
Cut all three holes with one split (Method B):
  • Surface param → Set One Surface → the slope
  • For each landform: Curve param → its footprint → Project (footprint → Curve input, slope → Brep input, Unit Z → Direction input). Group the pair and label it.
  • Merge → the three projected curves → D1, D2, D3 inputs
  • Surface Split → slope → Surface input, Merge Result → Curves input
  • List Item → Fragments → List input; set Index to whichever previews as the slope with three holes
Split once with all the curves. Splitting separately for each landform makes overlapping copies of the slope.
11 Patch → Join → Contour Grasshopper
  • In each group: Patch → projected curve → Curves input; control Point param → Points input (for the swale or ridge, Merge its curve into Curves instead)
  • Merge → List Item output + the three Patches
  • Join Breps → Merge Result → Breps input
  • Contour → joined terrain → Shape input; Number Slider → Distance input
12 Compose + Iterate Rhino Grasshopper
Edit the inputs in Rhino and watch everything update. No redoing steps.
  • Move a footprint and its control → reposition a landform on the site
  • Move a control point up or down → taller mound, deeper basin
  • Edit a footprint (F10 control points) → change where it stops
  • Read the whole site: does water shed off the mound, run down the swale, collect in the basin?
The three landforms are now one system. Iterate until the contours read as a deliberate site.
13 Bake + Produce the Deliverables Rhino
  • Right-click the Contour Contours output → Bake → layer CONTOURS-DESIGN. Bake the terrain too.
  • Make2D → Top viewport → flat linework
  • Layout → 1" = 20' (1:240) on 11 × 17. Add north arrow, scale bar, contour interval note, title block. Plot to PDF.
  • Capture an isometric of the combined site (as in Step 07)
