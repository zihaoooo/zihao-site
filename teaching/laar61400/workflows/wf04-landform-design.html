Session 1 — Site Setup + First Landform
00–01 File Setup + Base Slope Rhino
File setup — DocumentProperties → Units → Feet. Save as wf04-landform.3dm.
Build the base slope — Rectangle → 0,0 to 300,180. PlanarSrf from the rectangle. Press F10 to show control points. Ctrl+Shift+click one short edge to sub-object select it. Gumball Z → type 10 → Enter. F11 to hide points.
Sub-object selection (Ctrl+Shift+click) selects faces, edges, or vertices without exploding the object. Use it whenever you need to move part of a surface.
02 Draw a Footprint + Control Point Rhino
In the Top viewport, draw a closed curve: InterpCrv, Ellipse, or freehand. Then place a Point inside it.
  • Select the point → Gumball Z → drag above the slope for a mound, below it for a bowl or swale
  • Check its height in the Front or Right viewport against the slope
The curve is the breakline: the curb or edge where the landform stops. Everything outside it stays existing grade. The point is the peak or low point.
03 Project + Split the Base Grasshopper
Open Grasshopper (Grasshopper command). Cut a hole in the base slope where the landform goes:
  • Surface param → Set One Surface → the base slope
  • Curve param → Set One Curve → the footprint
  • Project → footprint → Curve input, base slope → Brep input, Unit Z → Direction input
  • Surface Split → base slope → Surface input, projected curve → Curves input
  • List Item → Fragments → List input; set Index to whichever previews as the base with the hole
Projecting puts the breakline on existing grade, so the landform starts exactly where the ground is.
04 Patch → Merge → Contour Grasshopper
Patch the hole with the new landform:
  • Point param → Set One Point → the control point
  • Patch → projected curve → Curves input, Point → Points input
  • Flexibility input: higher = looser, more organic; try 3–5. Spans input: higher = more detail
Merge and read the contours:
  • Merge → List Item output → D1 input, Patch output → D2 input
  • Contour → Merge Result → Shape input; Number Slider (0.5–5 ft) → Distance input (contour interval)
  • Don't use Join Breps: Patch only approximates its boundary, so its edge misses the hole by more than tolerance and the join fails. Contour doesn't need one surface; the contours still meet at the breakline
Shape it in Rhino, the contours update live:
  • Move the control point up or down → taller mound, deeper bowl
  • Move it off-center → one steep side, one gentle side
  • Edit the footprint (F10 control points) → change where the landform stops
The contours kink at the breakline. That is the point: the landform changes grade only inside its edge, the way a mound stops at a curb.
End of Session 1. Before next session: sketch two more landform operations on paper. Think about where water flows and where a hard edge is needed.
Session 2 — Full Site + Deliverable
05 Add More Landforms Grasshopper
Each new landform gets its own footprint, point, Project, and Patch. The base is still split once.
  • Copy the Curve → Project → Patch group (with its Point) for each landform; right-click → Group and label it
  • Merge all projected curves → Surface Split Curves input, so one split cuts every hole
  • Merge: the base with holes + every Patch (zoom in on Merge to add more D inputs) → Contour
  • Keep footprints from touching or crossing
Don't split the base separately for each landform. Each split makes its own copy of the base, and the copies overlap.
06 Build a Hard Edge Condition Grasshopper
In Rhino Top viewport, draw two curves: the top edge and bottom edge of the retaining wall. In Grasshopper:
  • Reference both curves
  • Move each to its correct elevation (top grade / bottom grade)
  • Loft → top curve + bottom curve → wall face surface
  • Trim grade surfaces to meet the wall edges → Join all
In the contour plan, contours overlap at the wall face — the same elevation appears on both the upper and lower grade. That overlap is how a retaining wall reads in a contour drawing.
07 Read the Contours Grasshopper
Before baking, read the contour output as a design drawing:
  • Contours that V upstream → valley or drainage path
  • Contours that V downstream → ridge
  • Are landform transitions reading as a continuous field or unintended hard edges?
  • Is the retaining wall placed where the grade change is legible and intentional?
Adjust footprint curves and height sliders until the plan reads as a coherent designed landscape.
08 Bake + Produce the Contour Plan Rhino
Bake the finished geometry and produce a print-ready layout:
  • Right-click the Contour Contours output → Bake → layer CONTOURS-DESIGN
  • Make2D → Top viewport → flat linework
  • Layout → 1" = 20' (1:240) on 11 × 17
  • Add: north arrow, scale bar, contour interval note, title block
  • Plot to PDF
09 Capture the Isometric View Rhino
Set up a standard isometric view and save it directly from Rhino:
  • In any viewport title, right-click → Set View → Isometric → choose SW, SE, NE, or NW — pick whichever shows the landform most clearly
  • Type PrintDisplay → On, to show lineweights in the viewport
  • Type PrintScreen → File → save as PNG or JPEG
PrintScreen to File captures exactly what you see in the viewport at screen resolution — no layout or PDF needed for this view.
Two Kinds of Surfaces
Smooth field — continuous transition across the ground. Footprint curve → Patch. Reads in plan as flowing, spaced contours.
Hard edge — abrupt grade change. Two edge curves → Loft. Reads in plan as overlapping contours at the wall face.
The plan curve is always the breakline. Drawing a footprint in Top view is a design decision — the shape, size, and placement of that curve determines how the landform reads in section and how water moves across the site.
