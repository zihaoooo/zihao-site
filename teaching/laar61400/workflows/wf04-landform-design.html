Learning Objectives

In WF06, Claude builds Rhino geometry for you through MCP: it picks the command, wires the inputs, fixes the join. That is button knowledge, and it is Claude's job now. Your job is knowing how surfaces behave. You learn that by building by hand, once. It is what lets you work with Claude:

  • Specify — say what you want in design terms: breakline, section, peak, grade
  • Evaluate — read the contours and see what is wrong: where water goes, where the form misses the intent
  • Direct — know which input to change next, and what it will do to the form
AssignmentA catalog of three landform types built by hand in Rhino, then combined on the 180×300 ft site as a live Grasshopper definition: four 11×17 isometric pages, one per landform and one of the combined site.

Session 1 — A Catalog of Landforms, by Hand
00–01 File Setup + Base Slope Rhino
File setup — DocumentProperties → Units → Feet, Absolute tolerance → 0.1. Save as wf04-landform.3dm.
Tolerance = how far apart two edges can be and still join. Patch only approximates its edge, so 0.01 ft is too tight; 0.1 ft (about 1") joins and is invisible at site scale.
Build the base slope — Rectangle → 0,0 to 300,180. PlanarSrf from the rectangle. Press F10 to show control points. Ctrl+Shift+click one short edge to sub-object select it. Gumball Z → type 10 → Enter. F11 to hide points.
Sub-object selection (Ctrl+Shift+click) selects faces, edges, or vertices without exploding the object. Use it whenever you need to move part of a surface.
Ways to Build a Surface Rhino
Every surface is built from curves. The curves you have decide the command.
CommandGive itLandform use
Lofttwo or more section curvesramp, terrace edge, wall face
Sweep1 / Sweep2a profile + one or two rails (paths)berm or swale along a path, channel
Patcha boundary curve + points or section curves inside itmound or bowl inside a footprint
This exercise uses Patch: a landform is defined by its edge plus a peak point or a section curve across it.
02 Draw a Footprint + Control Rhino
In the Top viewport, draw a closed curve, flat: InterpCrv, Ellipse, or freehand. Then add a control inside it: a point or a section curve.
  • Point → place it inside the footprint → Gumball Z → drag above the slope for a mound
  • Section curve → in the Front or Right viewport, draw an InterpCrv across the footprint, edge to edge, tracing the profile you want. Patch passes through it, so it shapes the whole cut, not just the peak.
  • Check heights in the Front or Right viewport
  • Copy the slope, footprint, and control 400 ft to the right (Copy, Ortho on). You will build the same landform two ways, side by side.
The footprint is the breakline: where the landform stops and existing grade continues. The control sets its height: a point fixes the peak, a section curve fixes a whole profile.
03 Method A: Patch Everything Rhino
On the left copy, rebuild the whole slope as one Patch:
  • DupBorder → select the slope → its edge as a curve
  • In the Top viewport: Project → the footprint → onto the slope. The curve now sits on existing grade.
  • Patch → the border, the projected curve, and the control → Enter → Surface U/V spans 10 → OK
  • Hide the original slope
One surface, nothing to join. But the mound is part of the whole field, so it can shift grade outside its footprint.
04 Method B: Split → Patch → Join Rhino
On the right copy, change the ground only inside the footprint:
  • Project → the footprint → onto the slope
  • Split → the slope → with the projected curve. Delete the cut-out piece.
  • Patch → the projected curve and the control → Enter → spans 10 → OK
  • Join → the slope with the hole + the Patch → "joined into one polysurface"
  • Check: ShowEdges → Naked edges. Only the site boundary should highlight.
More steps, but existing grade stays untouched outside the curve, the way a real landform stops at a curb. If Join fails, check the 0.1 ft tolerance from Step 00.
05 Contour Both: A First Look at Grasshopper Grasshopper
Rhino's Contour command draws contours once. In Grasshopper they stay live. Type Grasshopper:
  • Double-click the canvas → type Brep → Enter. Right-click it → Set Multiple Breps → select both results
  • Double-click → Contour. Wire Brep → Shape input
  • Double-click → Number Slider (0.5–5) → Distance input. Drag it and watch.
Compare A and B. In A, contours bend outside the footprint. In B, they kink at the breakline and stay straight beyond it. Session 2 builds the whole site with Method A.
06 Build the Catalog Rhino
Repeat Steps 02–04 for three landform types, each on its own copy of the slope, side by side. Pick Method A or B for each.
  • Mound → control point above the slope. Sheds water.
  • Basin → control point below the slope. Holds water.
  • Swale or ridge → an open curve inside the footprint, moved below or above the slope, instead of a point. Directs water.
Add all three to the Brep param (Set Multiple Breps) and read the contours. Where does water go on each?
07 Capture the Catalog Isometrics Rhino
One 11×17 isometric page per landform, with its contours. Three pages.
  • Right-click the Contour Contours output → Bake, so the contours are real Rhino curves
  • In any viewport title, right-click → Set View → Isometric → SW, SE, NE, or NW, whichever reads best
  • Type PrintDisplay → On, to show lineweights in the viewport
  • Zoom so one landform fills the view (Zoom → Selected)
  • Type ViewCaptureToFile → size 17 × 11 in, 300 dpi → uncheck Grid and Axes → Save as PNG
  • Check Transparent background if the image goes onto a colored board
ViewCaptureToFile renders the active viewport at any size, so it stays sharp in print, unlike a screenshot. These are pages 1–3. Want to change a landform now? Delete it and redo its steps by hand. Session 2 removes that loop.
Session 2 — Combine Them in Grasshopper
08 Set Up the Site Rhino
Start from scratch: a new Rhino file, saved as wf04-site.3dm. Redo Steps 00–01 (setup, slope).
  • Draw the three footprints from your catalog on the one slope. Keep them from touching.
  • Add each one's control: a point or a section curve
  • DupBorder → the slope → its edge as a curve
Rhino only holds these inputs. Everything after happens in Grasshopper. Save the definition as wf04-site.gh.
09 Grasshopper Basics Grasshopper
Every Rhino command from Session 1 becomes a component (see the reference table below).
  • Add a component: double-click the empty canvas → type its name → Enter
  • Inputs on the left, outputs on the right. Drag a wire from an output to an input.
  • Params (Surface, Curve, Point) hold Rhino geometry: right-click → Set One … → click it in Rhino
  • Hover any input to see what it expects. Orange = warning, red = error.
  • Grasshopper geometry is a preview only. It becomes real Rhino geometry when you Bake it.
10 Project the Footprints Grasshopper
Set each footprint on existing grade (Method A):
  • Surface param → Set One Surface → the slope
  • Curve param → Set One Curve → the border
  • For each landform: Curve param → its footprint → Project (footprint → Curve input, slope → Brep input, Unit Z → Direction input). Add a param for its control: Point or Curve. Group them and label the group.
The slope is only a reference here: Project needs it to find existing grade. The final terrain is one new surface.
11 Patch Everything → Contour Grasshopper
One Patch builds the whole site:
  • Merge → the border, the three projected footprints, and any section curves → Patch Curves input
  • Merge → the control points → Patch Points input
  • Number Slider (integer, 5–30) → Spans input. More spans follow the inputs more closely.
  • Contour → Patch output → Shape input; Number Slider (0.5–5) → Distance input
One surface, so there is nothing to split or join. The landforms share one field: each one pulls grade around it, and two close together blend.
12 Compose + Iterate Rhino Grasshopper
Edit the inputs in Rhino and watch everything update. No redoing steps.
  • Move a footprint and its control → reposition a landform on the site
  • Move a control point up or down → taller mound, deeper basin
  • Edit a section curve (F10 control points) → reshape its profile
  • Edit a footprint (F10 control points) → change where it stops
  • Move two landforms closer → watch them merge into one form
  • Read the whole site: does water shed off the mound, run down the swale, collect in the basin?
The three landforms are now one system. Iterate until the contours read as a deliberate site.
13 Bake + Capture the Site Isometric Rhino
  • Right-click the Contour Contours output → Bake → layer CONTOURS-DESIGN. Bake the terrain too.
  • Capture an 11×17 isometric of the combined site with ViewCaptureToFile, same settings as Step 07. This is page 4.
  • Submit all four pages to the Miro board

▸ Optional — Add a Retaining Wall Grasshopper
A smooth landform blends into grade. A retaining wall stops it with a hard edge. This example combines Method B with a wall:
  • In Rhino: Split the slope with the projected footprint and delete the cut-out. The Surface param holds the slope with its hole.
  • Wall face: Loft → two curves, the wall's foot on existing grade and its top edge raised to the wall height
  • Landform: Patch → the wall's top edge + the rest of the footprint + a section curve across it
  • Join Breps → slope + wall + Patch → Contour
At the wall face, contours crowd into a tight band; on a vertical wall they stack exactly. That band is how a wall reads in a contour drawing. Patch only approximates its edges, so it joins at the 0.1 ft tolerance from Step 00. If its edges stay naked, raise the Patch spans. The geometry is stored inside the definition, so it opens without a Rhino file.
