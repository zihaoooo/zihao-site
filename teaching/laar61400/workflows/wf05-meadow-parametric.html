A flat meadow. Two given rules encode two landscape conditions — a mown path, and wet areas. Then you design a meadow garden of your own, from ecology, experience, or both.
This workflow introduces the core logic of parametric design: write the rule first, then build it in nodes.
Session 1 — Mowing Path

A Pseudocode First On paper — no computers
Before opening Grasshopper, write this rule on paper:
FOR EACH plant in meadow:
  IF distance to path < mowing width
    THEN height = mowed (short)
  ELSE height = unmowed (tall, random)
Identify: what is the input, what is the condition, what are the two outputs.
01 Set Up the Meadow GH
Construct the site boundary in Grasshopper — 50 × 50 ft. No need to draw in Rhino:
  • Rectangle → set X and Y domains to 0 to 50 (use a Construct Domain or a Panel)
  • Populate 2D → the Rectangle as region
  • Count slider → start at 1000
  • Seed slider → controls the random distribution
+ Optional — Meadow on a Landform Rhino GH
Grow the meadow on a landform instead of flat ground — your WF04 surface, or a new one:
  • Reference the landform into GH with a Brep parameter. Make it larger than the 50 × 50 rectangle so every point lands on it.
  • Pull Point → points = Populate 2D points, geometry = landform. Its Closest Point output is the meadow on the ground, whether the ground sits above or below the flat points.
  • Use these Closest Points everywhere Populate 2D points go below
  • Bring the path and the attractors down too: Project (Curve › Util) for curves, B = landform; Pull Point for the attractor points. Pull Point measures in 3D, so a flat path under raised ground reads as far away and the mown strip disappears. Doing this in GH keeps them live when you move the originals.
  • A dashed wire means the data sits in several lists. Right-click the output and Flatten it.
02 Random Heights (Unmowed) GH
Give every plant a random unmowed height:
  • Random → domain via a Panel typed 2 to 6.0 (grass height range); set Number (N) to the same Count as Populate 2D
  • Line SDL → start = Populate 2D points, direction = unit Z, length = Random
You now have a meadow — a field of vertical lines of varying height.
03 Draw + Measure the Path Rhino GH
In Rhino, draw a curve across the site — polyline or arc. Reference it into GH with a Curve parameter, then measure how far each plant sits from it:
  • Pull Point → input points = Populate 2D points, geometry = path curve
  • Use the Distance output directly — one component does both
Same component as the Session 2 wet areas — Pull Point pulls to any geometry (curve here, points there) and returns the distance.
04 Apply the Rule — Dispatch GH
Split the meadow into mown and unmown by the threshold:
  • Larger Than → A = distance to path, B = mowing width slider (start at 2)
  • Dispatch → data = Populate 2D points, pattern = Larger Than → List A = unmowed points, List B = mowed points
  • Unmowed: rewire the Step 02 Line SDL → start = List A. Feed List Length of List A into Random's N, so each unmowed plant gets exactly one height
  • Mowed: a second Line SDL → start = List B, direction = unit Z, length = a short Length slider (0.5)
Only the points are dispatched. Random's N has to match the List A count — if it stays at Count, the extra heights stack up as hidden lines on the last unmowed plant. List A points carry forward into Session 2. End of Session 1.

Session 2 — Wet Areas

Open on YouTube for 1080p ↗
B Pseudocode First On paper — no computers 
FOR EACH plant in meadow:
  height = remap(distance to nearest wet area, 0 → max, tall → short)
Close to a wet area = tall (wet, lush). Far from a wet area = short (dry).
05 Place Wet-Area Attractors Rhino GH
In Rhino, place 2–4 point objects on the site — these are the wet area locations. Reference them into GH with a Point parameter. Then find the nearest wet area for each unmowed plant:
  • Pull Point → input points = List A points (unmowed, from Step 04 Dispatch), geometry = wet area attractors
  • Use the Distance output directly, same as Step 03 — distance from each unmowed plant to its nearest wet area
06 Remap to Height GH
Turn distance into a height gradient, capped at a maximum influence radius:
  • Three sliders: Max Radius (default 15 ft), Height Near (default 9), Height Far (default 1)
  • Minimum → A = distances (Pull Point D), B = Max Radius slider → output = capped distances (GH broadcasts the single slider value across the whole list)
  • Construct Domain (source) → A = 0, B = Max Radius → fixed source domain
  • Construct Domain (target) → A = Height Near, B = Height Far → target domain
  • Remap Numbers → values = output from Minimum, source = source domain, target = target domain
Plants inside the radius get a gradient; plants outside all map to exactly Height Far. Moving a wet-area point creates a visible zone with a clear edge between lush and dry.
07 Draw Plant Heights GH
Same as Session 1 — draw each unmowed plant as a vertical line, length = remapped height:
  • Line SDL → start = List A points (unmowed), direction = unit Z, length = remapped height
  • The remapped height replaces Random
  • The mowed branch (List B, 0.5) stays as it is
Tall lines near wet areas, short lines further away. The gradient reads immediately in the viewport.
08 Preview + Adjust Rhino
  • Move a wet area point in Rhino — the tall cluster shifts live
  • Add or remove wet area points — each makes a new zone of lush growth
  • Slide Height Near or Height Far to change the height contrast live

On Your Own — Meadow Garden
09 Design a Meadow Garden GH
Design three garden options on your Session 2 definition, from ecology, experience, or both. Use the same components with new logic:
  • Swap the attractor: points, a curve, or the site boundary
  • Flip the direction: short near the attractor
  • Use Dispatch where you used Remap, or the reverse
  • Remove plants: Dispatch, then draw one list only
Ecology. Reference: Teresa Galí-Izard, Arquitectura Agronomía.
  • Tree shade — trunk points; short in the shade, tall in the open. Remap, flipped.
  • Stream corridor — a stream curve; tall on the banks, short upland. Remap.
  • Deer browsing — bedding points; grazed short inside a radius. Dispatch.
  • Rock outcrops — bedrock points; nothing grows inside a radius. Dispatch, draw the outside only.
  • Woodland edge — tall along the site boundary, open in the middle. Pull Point to the Rectangle + Remap.
Experience. Reference: Catherine Dee, Form and Fabric in Landscape Architecture (2001).
  • Enclosure — tall grass as walls, short grass as floor
  • Garden rooms — mown patches of different sizes, joined by the path
  • Circulation — a wide main path and narrow side paths, each with its own mowing width
  • Sequence and rhythm — open and enclosed in turn along the path; Divide Curve for attractor points
  • Threshold — a narrow gap in tall grass before a room
Both — e.g. a mown room at the wet area, walled by tall sedge.
Model Rhino objects as needed — a wall, a landform. Capture all three from the same view (Set View → SE Isometric), each with a name and a short caption.
Key Concepts
Populate 2D vs. grid — Populate 2D distributes points organically within a boundary. The Seed slider changes the distribution without changing the count. It reads as a natural meadow, not a tile pattern.
Dispatch vs. Remap — Dispatch encodes a binary rule (mow / no mow). Remap encodes a continuous gradient (tall near water, short away). Most landscape conditions are gradients; the binary is the readable edge.
Pull Point — works like Closest Point: for each input point, finds the nearest geometry in a set and returns its location. Used here to measure proximity to the nearest wet area across multiple attractors.
Line SDL — the same component used in Session 1. Start point, direction, length. Swapping the length input from Random to a Remap value is the only change — the drawing logic stays identical.
