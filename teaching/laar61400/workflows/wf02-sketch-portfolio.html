01 Photograph the Site
Walk the site and photograph it. Sort the photos into a folder before opening Photoshop.
  • Take overlapping frames — turn in place, or step along a path
02 Build the Site Joiner Photoshop
Assemble overlapping site photos into a composite — reference David Hockney's joiners. Multiple perspectives, visible seams. Use T (Transform) to scale and position each piece.
  • Don't stitch seamlessly — the overlap and fragmentation are part of the drawing
  • Try a horizontal strip for a spatial sequence
  • Expand the canvas as you go: Image → Canvas Size
03 Trace Over a Print Trace paper
Print the joiner. Lay trace paper over it and draw — trace edges, hatch surfaces, write notes on what you see. Then scan the trace.
  • Before drawing, mark two corners of the print on the trace — they line the scan up later
  • Draw what the photo can't show: edges, flows, conditions, questions
  • Scan at 300 dpi, grayscale. Adobe Scan or Microsoft Lens work for phone capture.
04 Combine into a Hybrid Photoshop
Place the scanned trace on a layer above the joiner and set its blending mode to Multiply — the paper drops out and only your lines remain. Line it up using the corner marks. Keep the layers; Step 05 sets them on the sheet.
  • Ctrl L (Levels) on the scan pushes the paper to pure white and the lines to black
  • Lower the photo layer's opacity so the linework leads
05 Export the Sheet Photoshop
Set the hybrid on an 11"×17" sheet and save it as a PDF.
  • Image → Canvas Size → 17 × 11 in, landscape. Check Image → Image Size reads 300 dpi.
  • Add a title and a few notes with the Type tool T, on their own layer
  • File → Save a Copy → Photoshop PDF
