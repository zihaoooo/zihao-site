Part 1 — Hybrid Drawing
01 Photograph the Site
Walk the site and photograph it. Sort the photos into a folder before opening Photoshop.
  • For the joiner, take overlapping frames — turn in place, or step along a path
  • For the texture palette in Part 2, take close-ups of surfaces and materials
02 Build the Site Joiner Photoshop
Assemble overlapping site photos into a composite — reference David Hockney's joiners. Multiple perspectives, visible seams. Use T (Transform) to scale and position each piece.
  • Don't stitch seamlessly — the overlap and fragmentation are part of the drawing
  • Try a horizontal strip for a spatial sequence
  • Expand the canvas as you go: Image → Canvas Size
03 Trace Over a Print Trace paper
Print the joiner. Lay trace paper over it and draw — trace edges, hatch surfaces, write notes on what you see. Then scan the trace.
  • Before drawing, mark two corners of the print on the trace — they line the scan up later
  • Draw what the photo can't show: edges, flows, conditions, questions
  • Scan at 300 dpi, grayscale. Adobe Scan or Microsoft Lens work for phone capture.
04 Combine into a Hybrid Photoshop
Place the scanned trace on a layer above the joiner and set its blending mode to Multiply — the paper drops out and only your lines remain. Line it up using the corner marks. Save the hybrid as a flattened image for InDesign.
  • Ctrl L (Levels) on the scan pushes the paper to pure white and the lines to black
  • Lower the photo layer's opacity so the linework leads
Part 2 — Layout in InDesign
05 Set Up the Deck InDesign
New multi-page document: 11"×17" landscape, 0.125" bleed. Build a parent page with repeating elements. Define paragraph styles for title, caption, and annotation — apply consistently, never format manually.
  • Plan pages before building: hybrid spread · texture palette
  • Parent page: page number, course name, margin rules
  • Paragraph Styles F11: Title, Caption, Annotation — at minimum
06 Lay Out the Hybrid Spread InDesign
Place the hybrid drawing — full bleed or within margins. Float text frames over the image. The page should feel like a drawing, not a photograph layout.
  • Ctrl D to place; Ctrl Alt Shift E to fill frame
  • Keep text on its own layer above the image
  • Direct Selection tool A to reposition image within crop
07 Build the Texture Palette InDesign
A small-multiple grid of material close-ups — equal frames, each captioned with material, location, and a brief condition note. A site texture inventory.
  • Step and Repeat Ctrl Alt U to build the grid
  • Select all frames → Ctrl D to load and place multiple images at once
  • Caption format: material · location · one observation
08 Export PDF InDesign
Export the full deck as a single PDF.
  • Ctrl E → PDF (Print) with bleed and crop marks for physical output
  • PDF (Interactive) for screen sharing — smaller file, no bleed needed
  • Package Ctrl Alt Shift P before sharing to collect all linked files
InDesign and Coding Agents
InDesign can also save as IDML (File → Save As → InDesign Markup). IDML is XML, a plain-text markup language, so a coding agent like Claude can read and edit it — restyle every caption, rebuild the texture grid, add pages. Open the edited file back in InDesign.
